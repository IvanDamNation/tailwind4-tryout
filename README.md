## About

First tryout in Tailwind CSS v4

#### Starting up (all commands in project root dir)

- Use `pnpm i` before first start

```
pnpm i
```

- Use `pnpm dev` to start server

```
pnpm dev
```

- Use `pnpm build` to make a bundle

```
pnpm build
```

- Use `pnpm preview` to check proper work of bundle

```
pnpm preview
```
